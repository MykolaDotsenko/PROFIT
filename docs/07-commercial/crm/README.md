# CRM

Domain and workflow knowledge for farm CRM.

- suppliers;
- buyers;
- advisers;
- contractors;
- veterinarians/agronomists;
- relationship history;
- contacts and organisations;
- calls/tasks/follow-ups;
- offers and opportunities;
- documents;
- segmentation;
- relationship performance.

Product-specific CRM requirements belong in `02-product/modules/`.
