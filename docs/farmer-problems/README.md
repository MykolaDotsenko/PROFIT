Real problems farmers face in day-to-day operations.

## Categories
- `pigs/`
- `cows/`

Keep problems here — not product solutions.

For each problem record:
1. what happens;
2. who experiences it;
3. frequency;
4. business impact;
5. current workaround;
6. evidence;
7. possible PROFIT opportunity.
