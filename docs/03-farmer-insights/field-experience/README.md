# First-hand Field Experience

Capture practical knowledge from the team's own agricultural work.

Recommended structure for each note:
- country / farm / production type;
- role and responsibilities;
- workflow observed;
- problem encountered;
- current workaround;
- operational or financial consequence;
- what data existed or was missing;
- lesson for PROFIT;
- confidence / whether this is generalisable.

Keep raw experience separate from product requirements.
