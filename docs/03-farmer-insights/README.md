# Farmer Insights

This is one of the most important folders in PROFIT.

Store evidence about farmers' real work, friction and decisions:
- first-hand experience;
- recurring pain points;
- interviews;
- observed workflows;
- workarounds and spreadsheets;
- mistakes and failure modes;
- decision delays;
- information gaps;
- willingness-to-pay signals.

Do not jump directly from an anecdote to a product feature. Capture evidence first, then validate and link it to a product specification.
