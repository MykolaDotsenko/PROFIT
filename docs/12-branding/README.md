# Branding

This folder contains all PROFIT brand planning and brand decisions.

Use it in this order:

1. `brand-strategy.md` — what the brand should represent.
2. `name-and-slogan.md` — company/product name and slogan development.
3. `logo.md` — logo concept, requirements and evaluation.
4. `visual-identity.md` — colors, typography, iconography and visual language.
5. `messaging-tone-of-voice.md` — brand message and communication style.
6. `brand-risk-checklist.md` — trademark, domain, language and market risks.
7. `brand-guidelines.md` — final approved brand rules.
8. `brand-assets/` — approved brand assets and references.

## Rule

Keep exploration and final decisions separate.

Every major brand decision should record:
- objective;
- options considered;
- evaluation criteria;
- risks;
- final decision;
- reason for the decision.
