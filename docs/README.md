# PROFIT Documentation

Only eight main areas:

- `product/` — product strategy, planning, MVP, roadmap, requirements, UX and modules.
- `farmer-problems/` — real farmer problems: pigs, cows, vegetables, field crops and general.
- `crop-production/` — crop-production knowledge and risks.
- `livestock/` — livestock, dairy and swine knowledge.
- `farm-economics/` — profitability, costs, ROI, formulas and KPIs.
- `branding/` — brand strategy, name, slogan, logo and visual identity.
- `engineering/` — architecture, technology stack, data, integrations and development workflow.
- `market/` — competitors, pricing, monetization, sales, marketing and SEO.

## Product Rule

**Farmer problem → target user → evidence → expected value → MVP → requirements → implementation → measurement**

Do not create a new folder unless there is enough documentation to justify it.
Do not duplicate the same information in multiple places.
