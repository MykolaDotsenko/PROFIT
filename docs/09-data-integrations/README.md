# Data and Integrations

Use this area for:
- domain data model;
- external data sources;
- APIs and integrations;
- imports and exports;
- data quality;
- licensing and reliability notes.

## External Data Source Catalog

For each candidate or integrated source record:
- provider;
- data type;
- geography;
- update frequency;
- API/access method;
- pricing;
- license/usage restrictions;
- reliability;
- data quality;
- PROFIT use case;
- integration status.

Relevant categories include:
- weather;
- satellite;
- soil;
- commodity/market prices;
- public/government agricultural datasets;
- accounting;
- machinery/IoT;
- farm-management systems.

Do not add a data source unless there is a clear product use case.
