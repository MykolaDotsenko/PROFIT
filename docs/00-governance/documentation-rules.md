# Documentation Rules

Status: Accepted
Owner: PROFIT team
Last reviewed: 2026-09-23
Evidence level: Internal standard
Related product module: N/A

## Rules
1. One canonical home per concept; link instead of duplicating.
2. Separate observed fact, source-backed fact, interpretation and hypothesis.
3. Record source/date for externally derived claims.
4. First-hand farmer experience must state context: country, farm type, production system, scale and role.
5. Product requirements must reference the farmer/business problem they solve.
6. Financial formulas must have a canonical definition and test examples.
7. Superseded decisions remain searchable and point to the replacement.
8. Prefer small focused documents over one giant wiki page.
9. Use lowercase kebab-case filenames.
10. Review high-impact product/economic/security documents whenever implementation changes.
