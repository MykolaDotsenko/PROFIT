# Prioritization Framework

Use prioritization to compare problems and product work consistently.

## Step 1 — Problem Quality
Evaluate:
- frequency;
- economic impact;
- urgency;
- number of affected farms/users;
- strength of evidence.

## Step 2 — Product Value
Evaluate:
- expected user outcome;
- strategic fit;
- differentiation;
- revenue/retention potential;
- learning value.

## Step 3 — Delivery Cost
Evaluate:
- engineering effort;
- data dependency;
- integration complexity;
- UX complexity;
- operational/support burden;
- risk.

## Simple Priority Formula

Priority should increase with:
**Impact × Evidence × Strategic Fit**

Priority should decrease with:
**Effort × Risk**

Do not treat the formula as automatic truth. Record the reasoning.

## Required Before Commitment
Every major roadmap item should link to:
- farmer problem;
- target segment;
- measurable outcome;
- owner;
- estimated effort;
- key risks/dependencies.
