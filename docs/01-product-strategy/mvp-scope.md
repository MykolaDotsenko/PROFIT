# MVP Scope

## MVP Objective
What must the first production-ready version prove?

## Target User
Who is the MVP for?

## Core Problem
Which farmer problem must the MVP solve?

## Core Workflow
Describe the shortest end-to-end workflow that creates real value.

## Must Have
Only functionality required to complete the core workflow safely and reliably.

## Should Have
Useful after the core workflow works.

## Later
Important but not required to validate the MVP.

## Explicitly Out of Scope
List features that will not be included.

## MVP Success Criteria
Define measurable signals such as:
- user completes the workflow;
- economic calculation is correct;
- time saved;
- decision improved;
- repeated use;
- willingness to pay.

## Exit Criteria
What evidence allows PROFIT to move beyond MVP?
