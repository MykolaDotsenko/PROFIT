# Data and Integrations

Use this file for:
- domain data model;
- external data sources;
- APIs and integrations;
- imports and exports;
- data quality;
- licensing and reliability.

For each external source record:
- provider;
- data type;
- geography;
- update frequency;
- access method;
- pricing;
- license restrictions;
- reliability;
- data quality;
- PROFIT use case;
- integration status.

Relevant categories:
- weather;
- satellite;
- soil;
- market prices;
- public agricultural data;
- accounting;
- machinery/IoT;
- farm-management systems.

Do not add a source without a clear product use case.
