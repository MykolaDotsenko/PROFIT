# Farm Economics Formulas and KPIs

For every formula or KPI record:
- name;
- purpose;
- formula;
- units;
- inputs;
- assumptions;
- rounding rules;
- example;
- source;
- validation tests;
- version notes.

Examples:
- cost per hectare;
- cost per kg / liter / animal;
- contribution margin;
- gross margin;
- break-even;
- ROI;
- working capital;
- field profitability;
- herd/unit profitability;
- plan vs actual variance.
