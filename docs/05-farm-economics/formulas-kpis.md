# Farm Economics Formulas and KPIs

Maintain canonical economic formulas, definitions, units, assumptions and validation examples here.

For every formula or KPI record:
- name;
- purpose;
- formula;
- units;
- required inputs;
- assumptions;
- rounding rules;
- example calculation;
- source/reference;
- validation tests;
- version/change notes.

Examples:
- cost per hectare;
- cost per kg / liter / animal;
- contribution margin;
- gross margin;
- break-even;
- ROI;
- working capital;
- field profitability;
- herd/unit profitability;
- plan vs actual variance.
