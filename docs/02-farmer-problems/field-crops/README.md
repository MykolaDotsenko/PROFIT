# Field Crop Problems

Real problems in grains, oilseeds and other field crops.

Examples:
- seed, fertilizer and chemical costs;
- weather risk;
- yield variability;
- field-operation timing;
- machinery and fuel costs;
- crop rotation;
- inventory control;
- harvest losses;
- market-price risk;
- profitability by field and crop.

Create one Markdown file per important problem.
