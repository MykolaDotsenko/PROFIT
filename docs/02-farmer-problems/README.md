# Farmer Problems

This section stores real problems farmers face in day-to-day operations.

## Categories

- `pigs/` — pig farming problems
- `cows/` — dairy and cattle problems
- `vegetables/` — vegetable production problems
- `field-crops/` — grains, oilseeds and other field-crop problems
- `general/` — problems common to several farm types

Keep problems here — not product solutions.

For each problem, record:
1. What exactly happens?
2. Who experiences it?
3. How often?
4. What does it cost in money, time, yield or risk?
5. How is it handled today?
6. What evidence do we have?
7. Could PROFIT solve or reduce it?
