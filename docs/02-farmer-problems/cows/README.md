# Cow and Dairy Problems

Real problems in dairy and cattle operations.

Examples:
- milk yield variation;
- feed cost and ration efficiency;
- reproduction and calving;
- mastitis and animal health;
- labor and milking routines;
- herd records;
- cost per liter of milk;
- culling decisions;
- weak visibility into cow or herd profitability.

Create one Markdown file per important problem.
