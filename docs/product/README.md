# Product

All product planning and design documentation lives here.

## Core files

- `strategy.md` — vision, target customers and value proposition.
- `planning.md` — discovery, prioritization, business case, risks and readiness.
- `personas-jtbd.md` — user roles and Jobs To Be Done.
- `mvp.md` — MVP scope and success criteria.
- `roadmap.md` — Now / Next / Later.
- `metrics.md` — product and business KPIs.
- `requirements.md` — PRD / feature specification template.
- `ux.md` — user flows and UX rules.
- `modules/` — documentation for individual PROFIT modules.

Product work should start from a documented farmer problem.
