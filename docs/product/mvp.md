# MVP

## Objective
What must the first production-ready version prove?

## Target User
Who is it for?

## Core Problem
Which farmer problem must it solve?

## Core Workflow
What is the shortest end-to-end workflow that creates real value?

## Must Have
Only what is required to complete the core workflow reliably.

## Later
Everything that can wait.

## Out of Scope
Explicitly list what is not included.

## Success Criteria
Examples:
- workflow completed;
- calculation correct;
- time saved;
- decision improved;
- repeated use;
- willingness to pay.
