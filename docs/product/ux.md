# UX and Design

Keep UX focused on real farmer workflows rather than isolated screens.

For each important workflow document:

1. **User** — who performs it?
2. **Trigger** — what starts it?
3. **Goal** — what must be achieved?
4. **Steps** — start to finish.
5. **Data** — required or produced.
6. **Decisions** — choices the user makes.
7. **Errors / Edge Cases** — what can go wrong?
8. **Success State** — what completion looks like.
9. **Related Problem** — link the farmer problem.
10. **Related Requirements** — link the specification.
