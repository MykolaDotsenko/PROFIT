# Product Specifications

Use one specification per coherent capability or vertical slice.

Examples:
- field-profitability-v1.md
- inventory-control-v1.md
- crm-farmer-relationships-v1.md
- pig-production-economics-v1.md

Use `docs/_templates/product-spec.md`.

A specification defines **what PROFIT must do and why**. Domain knowledge belongs elsewhere.
