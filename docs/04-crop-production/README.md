# Crop Production

Domain knowledge for crop production.

Recommended substructure:
- `crops/` — wheat, barley, maize, sunflower, rapeseed, etc.;
- `agronomy/` — rotations, nutrition, crop protection, soil;
- `operations/` — seeding, spraying, fertilising, harvest;
- `economics/` — yield response, input cost, margin;
- `risk/` — weather, disease, price, operational risk;
- `data/` — field, soil, weather, machinery and satellite data.

This folder describes farming reality, not UI features.
