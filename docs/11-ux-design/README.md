# UX and Design

Use this area for user experience, screens, flows, usability findings and design-system decisions.

## User Flow Template

For each important workflow document:

1. **User** — who performs the workflow?
2. **Trigger** — what starts it?
3. **Goal** — what does the user need to achieve?
4. **Steps** — what happens from start to finish?
5. **Data** — what information is required or produced?
6. **Decisions** — where must the user make a choice?
7. **Errors / Edge Cases** — what can go wrong?
8. **Success State** — what does completion look like?
9. **Related Problem** — link to the farmer problem.
10. **Related Requirements** — link to the specification.

Keep UX documentation focused on real workflows rather than isolated screens.
